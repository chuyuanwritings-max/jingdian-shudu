## 0.4 改了什么（2026-11-20，Cc 试玩 0.3，总指挥转达）
Cc：「我填上去数字的时候，能不能给我一点反馈啊？以及最后真的整个通关的时候，我要有那种超爽的大反馈……能不能有一些字带有物理模型的感觉，像是一个数字方块放上去的那种感觉？」拆解见 `../手感拆解_0.4.md`。

## 有什么
- **六档难度**：入门、简单、中等、困难、专家、大师。题库 1500 题（入门到困难各 300，专家、大师各 150）。
- **局内**：点一格高亮同行、同列、同宫和相同数字；笔记（填对后同行列宫的笔记自动擦）；撤销、橡皮、提示；错 3 次算输（设置里可关）；计时、暂停盖住棋盘；某个数填满 9 个，数字键变灰（键下小字 = 还剩几个）；每一步自动存档，退出再进「继续游戏」。
- **计分**（学 Sudoku 2）：填对一格 = 这一档基础分 × 速度倍数（5 秒内 ×2，30 秒降到 ×1）；填满一行 / 列 / 宫、某个数满 9 个另加分；填错过的格子之后填对只给一半；提示填的不给分。数都在 `js/config.js`。
- **填对的高光**：数字弹一下 + 一圈光晕扩散；填满一行 / 列 / 宫，从这格往两边扫一道光；某个数满 9 个，9 个一起闪金色；赢了整盘从左上到右下亮一遍。
- **手感**：点格子、点数字都在手指按下那一刻生效；每次有效点击轻震，填错重震；没东西动的时候不重画（省电不发热），有动画时 60 帧。
- **教学五课**（简单难度要的招）：规则 → 最后一格 → 排除法 → 唯一候选 → 笔记。每课先看手指演示，再自己点；点错一次或停几秒，手指出来指。第一次打开直接进第 1 课（可跳过）。局内提示也能点「学这招」跳到对应那一课，学完回到这一局。
- **提示分两步**：先说用哪一招、亮出看哪一片；点「填上」才直接填。每局送 1 次，之后看激励视频。
- **每日挑战**：月历，每天一题（同一天大家同一题，星期几决定难度），做完打勾；奖杯按本月完成几天填满。
- **战绩**：每档十项（已玩、赢、胜率、无错误赢、最好用时、平均用时、当前连胜、最长连胜、最高分、每日完成天数）。
- **好友排行榜**：微信开放数据域（`openDataContext/`），每档一张 + 每日挑战本月一张。**浏览器里看不到好友**（微信规定），只显示自己的成绩；要用真 AppID 在开发者工具或真机里看。
- **数独练脑页**：一屏，引用 Brooker 2019（1.9 万人，相关不等于因果）、斯坦福长寿中心 2014 联合声明、Simons 2016 综述；不说能防痴呆。
- **广告**（解题时一个都不出现，不放横幅）：提示（第 2 次起）、错 3 次再给一次机会、结算页解锁配色。原型里是 3 秒假倒计时；`js/config.js` 的 `ADS` 填上广告位 id 就放真激励视频。
- **五套配色**：清晨、夜间免费；薄荷、暖杏、雾紫在结算页看视频解锁。

## 难度怎么定
解题器（`js/sudoku.js`）每一步从最简单的招开始试，用到的最难一招 = 这道题的档：

| 档 | 最难用到的招 | 平均给数 |
| --- | --- | --- |
| 入门 | 最后一格、宫内排除 | 40.1 |
| 简单 | + 行列排除、唯一候选 | 34.1 |
| 中等 | + 区块排除 | 28.6 |
| 困难 | + 显性 / 隐性数对 | 27.4 |
| 专家 | + 三数组、X-Wing | 27.8 |
| 大师 | + XY-Wing、剑鱼 | 27.8 |

每题出库前都验：只有一个解；只用这一档及以下的招能解完（永远不用猜）；解题器每一步填的数、删的候选都和正确答案核对过（删错了说明哪一招写错了，会直接报错）。
