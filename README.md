## 0.10（2026-11-24，Cc：「这个怎么用了排除法？你得告诉我呀……最好能迅速闪过我的思维链，有一道光顺着排除法的思维链划过去」+ 技法统计、小樱、新手教学、主页放好友榜和对战、写版本号）
- **认招**（`sudoku.explain`）：每填对一格，回到填之前的盘面找最简单的理由——最后一格 → 宫内排除 → 行列排除 → 唯一候选；都不行就先用一步删候选的招（区块排除、数对……）再看。链上最难的那一步 = 你用的招。80 题实测：中等一招题每题区块排除约 3.5 次、困难数对约 2.5 次，0.01 毫秒一格。
- **思维链闪光**：排除法 = 别处的同一个数各放一道金光，顺着它那一行 / 列扫过去，扫到的格子打叉，剩下那一格亮金；唯一候选 = 周围 8 个不同的数各连一道光过来；区块排除 / 数对 = 先亮出那几格、把被删的格子打叉，再同上。不挡操作，设置里能关（「填对时闪过思路」）。
- **本局一招改成按认招计数**：认出来用的正是这一招才算一次（以前是「填了关键格就算」）。
- **越档提醒**：用了比这一档更难的招，小樱「哇！你用了「区块排除」，这是「中等」的招！」（每局每招一次）。结算数据卡加「这局用的招：排除法 28 · 唯一候选 4 · 区块排除 3」，进度表加「我最常用的招」（累计）。
- **小樱**（`js/sakura.js`，人设 `../小樱_角色设计_1.0.md`）：信息行右下的小老师，气泡说话；开局、认招、越档、9 个齐、填错、45 秒没动都会说一句；六个表情。现在是代码画的简笔占位，立绘任务写好在 `../生图/Gemini/任务/01_小樱.json`（Cc 双击 `../生图/Gemini/开始生图.command`）。布局表 `play.sakura`，编辑器里能拖。

## 0.7.2（2026-11-21，Cc：「只有我填进去的……数字是立体的，其他并不立体，而且颜色显得特别乱……你去看一下 Sudoku 一共有几种颜色，再去看一下手机游戏《Sudoku 2》……你模仿它的方式来做」）
对照 App Store 截图：Sudoku.com 是一种蓝分三档深浅（同行同列同宫 / 相同数字 / 选中格）+ 黑字 + 蓝字 + 红字，全是平的；Sudoku 2（▻Sudoku）在原木、纸、金属、玻璃主题里**每个数字都是同一种方块**（题目原有的和自己填的一样），空格是凹下去的槽，点一个数只给所有相同的数套**一种颜色的框**，**不染同行同列同宫**；一套主题大约四种颜色 + 一种高亮色。我们之前把两家混在一起（蓝色行列带 + 黄色同数 + 白块蓝字 + 黑字），所以乱。现在照 Sudoku 2：
- 81 格：有数字的都是方块（题目原有的也是），空格是浅浅的凹槽；一套主题只一种方块、一种字色（去掉自己填的蓝字）。
- 高亮只剩黄色：相同数字的方块染黄 + 黄框；笔记里有这个数的格子淡黄；选中的格子一圈黄框；提示指的那一宫淡黄。**去掉同行同列同宫的蓝灰带。**
- 数字键也换成一排方块（学 Sudoku 2，每块微微歪一点），正在亮的数字那块染黄；去掉蓝字。
- 填错仍是红方块；教学里的金色区域、红线不变。

## 有什么
- **六档难度**：入门、简单、中等、困难、专家、大师。题库 1500 题（入门到困难各 300，专家、大师各 150）。
- **局内**：点一格高亮同行、同列、同宫和相同数字；笔记（填对后同行列宫的笔记自动擦）；撤销、橡皮、提示；错 3 次算输（设置里可关）；计时、暂停盖住棋盘；某个数填满 9 个，数字键变灰（键下小字 = 还剩几个）；每一步自动存档，退出再进「继续游戏」。
- **计分**（学 Sudoku 2）：填对一格 = 这一档基础分 × 速度倍数（5 秒内 ×2，30 秒降到 ×1）；填满一行 / 列 / 宫、某个数满 9 个另加分；填错过的格子之后填对只给一半；提示填的不给分。数都在 `js/config.js`。
- **填对的高光**：数字弹一下 + 一圈光晕扩散；填满一行 / 列 / 宫，从这格往两边扫一道光；某个数满 9 个，9 个一起闪金色；赢了整盘从左上到右下亮一遍。
- **手感**：点格子、点数字都在手指按下那一刻生效；每次有效点击轻震，填错重震；没东西动的时候不重画（省电不发热），有动画时 60 帧。
- **教学五课**（简单难度要的招）：规则 → 最后一格 → 排除法 → 唯一候选 → 笔记。每课先看手指演示，再自己点；点错一次或停几秒，手指出来指。第一次打开直接进第 1 课（可跳过）。局内提示也能点「学这招」跳到对应那一课，学完回到这一局。
- **提示分两步**：先说用哪一招、亮出看哪一片；点「填上」才直接填。每局送 1 次，之后看激励视频。
- **每日挑战**：月历，每天一题（同一天大家同一题，星期几决定难度），做完打勾；奖杯按本月完成几天填满。
- **战绩**：每档十项（已玩、赢、胜率、无错误赢、最好用时、平均用时、当前连胜、最长连胜、最高分、每日完成天数）。
- **好友排行榜**：微信开放数据域（`openDataContext/`），每档一张 + 每日挑战本月一张。**浏览器里看不到好友**（微信规定），只显示自己的成绩；要用真 AppID 在开发者工具或真机里看。
- **数独练脑页**：一屏，引用 Brooker 2019（1.9 万人，相关不等于因果）、斯坦福长寿中心 2014 联合声明、Simons 2016 综述；不说能防痴呆。
- **广告**（解题时一个都不出现，不放横幅）：提示（第 2 次起）、错 3 次再给一次机会、结算页解锁配色。原型里是 3 秒假倒计时；`js/config.js` 的 `ADS` 填上广告位 id 就放真激励视频。
- **五套配色**：清晨、夜间免费；薄荷、暖杏、雾紫在结算页看视频解锁。

## 难度怎么定
解题器（`js/sudoku.js`）每一步从最简单的招开始试，用到的最难一招 = 这道题的档：

| 档 | 最难用到的招 | 平均给数 |
| --- | --- | --- |
| 入门 | 最后一格、宫内排除 | 40.1 |
| 简单 | + 行列排除、唯一候选 | 34.1 |
| 中等 | + 区块排除 | 28.6 |
| 困难 | + 显性 / 隐性数对 | 27.4 |
| 专家 | + 三数组、X-Wing | 27.8 |
| 大师 | + XY-Wing、剑鱼 | 27.8 |

每题出库前都验：只有一个解；只用这一档及以下的招能解完（永远不用猜）；解题器每一步填的数、删的候选都和正确答案核对过（删错了说明哪一招写错了，会直接报错）。
